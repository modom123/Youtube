📖 Quick Setup Guide
🤖
1. Anthropic API
Required for AI script generation using Claude.
1. Go to console.anthropic.com
2. Create an API key
3. Add to .env: ANTHROPIC_API_KEY=sk-ant-...
🖼️
2. Pexels API
Free stock photos and videos for your content.
1. Go to pexels.com/api
2. Create free account
3. Add to .env: PEXELS_API_KEY=...
▶️
3. YouTube
Upload videos and Shorts to your channel.
1. console.cloud.google.com
2. Enable YouTube Data API v3
3. Create OAuth 2.0 credentials
4. Add Client ID + Secret to .env
🎵
4. TikTok
Post videos directly to TikTok.
1. developers.tiktok.com
2. Create an app
3. Apply for Content Posting API
4. Add Client Key + Secret to .env
📸
5. Instagram
Publish Reels to your Instagram account.
1. developers.facebook.com
2. Create Meta App
3. Add Instagram Basic Display
4. Generate long-lived access token
5. Connect via Accounts → Instagram
🎬
6. Google Flow (Veo 2)
AI-generated cinematic video clips — no stock footage needed.
1. Go to aistudio.google.com
2. Click Get API Key
3. Copy the key
4. Add to .env: GOOGLE_API_KEY=AI...
5. Select "Google Flow" on the Create page
🤖
7. Social Optimize AI Video Engine
Powers AI video generation — Kling, Veo, Cinema Studio, Seedance, Wan, and more.
⚠️ Wrong value detected — You entered the endpoint URL, not the API token.

The endpoint (https://mcp.higgsfield.ai/mcp) is already built into the app — you do not need to set it.

What you need is your API Bearer Token (a long alphanumeric key from the Higgsfield dashboard).
In Render → Environment, set: HIGGSFIELD_MCP_TOKEN = <your-bearer-token>
How to get your AI token:
1. Log in to your Higgsfield AI account
2. Go to Account → API Keys (or Settings → Tokens)
3. Copy the Bearer token (looks like: hf_xxxxxxxxxxxxxx...)

In Render dashboard → your service → Environment:
Add variable name: HIGGSFIELD_MCP_TOKEN
Value: paste your bearer token here

⚠️ Do NOT paste the URL — the URL is already in the app code.
